# Estructuras de datos: Stack, Queue y Dictionary en C++

Las estructuras son:

- Stack (LIFO) el último elemento que entra es el primero que sale.
- Queue (FIFO) el primer elemento que entra es el primero que sale.
- Dictonary guarda datos como pares clave → valor.

## Métodos principales

### Stack

- push(valor): agrega un elemento al tope.
- pop(): elimina y regresa el elemento del tope.
- top(): consulta el elemento del tope sin eliminarlo.
- isEmpty(): indica si la pila está vacía.
- size(): regresa el número de elementos.
- clear(): vacía la pila.

### Queue

- enqueue(valor): agrega un elemento al final.
- dequeue(): elimina y regresa el elemento del frente.
- front(): consulta el elemento del frente sin eliminarlo.
- isEmpty(): indica si la cola está vacía.
- size(): regresa el número de elementos.
- clear(): vacía la cola.


### Dictionary

- put(clave, valor): agrega una pareja clave-valor o actualiza una clave existente.
- get(clave): recupera el valor asociado a una clave.
- contains(clave): indica si una clave existe.
- remove(clave): elimina una clave y su valor.
- isEmpty(): indica si el diccionario está vacío.
- size(): regresa el número de elementos.
- clear(): vacía el diccionario.
